# Attach files for agents

This page helps you give agents the documents they need, such as a brief, a
spec, a price list or a photo of a sketch.

You can add files to a whole **app**, so every goal and piece of work on it
gets them, or to one **goal**, so only the work for that goal gets them. Your
project lead and the agents read them while they work, and can use them in the
app, for example the text of a price list or a logo the task asked for.

Please never attach patient records or other personal information. Decurion
does not handle health or personal data.

## Add files to an app

1. Open **Apps**, then the app. (Or open **Settings**, then **Apps**, then
   the app: it has the same files.)
2. Open its **Files** tab.
3. Click **Add files** and choose one or more files. On a PC you can also drag
   files onto that box.

Each file shows **Adding** and its name while it goes up. Then it shows in the list.

## Add files to one goal

1. Open the goal on the **Goals** page. On your phone, tap the **Goals** tab.
2. Tap the **Files** tab, then **Add files to this goal**. Or tap the paperclip
   next to the message box.
3. Choose the files. On a phone you can also take a photo or pick one from your
   photos.

On a wide screen there are no tabs: the files show under **Pieces of work**.

The **Files** tab also shows the app's own files, under **For the whole app**.
You add and remove those on the app's **Files** tab under **Apps**.

## What agents can read

- **Word, Excel and PowerPoint** (.docx, .xlsx, .pptx): Decurion takes the text
  out for the agents. The file shows about how many words they get.
- **PDFs and pictures**: agents read them directly, the way you would.
- **Text and Markdown** (.txt, .md, .csv): agents read them as they are.
- **Old Word and Excel files** (.doc, .xls, .ppt): agents may not be able to
  read them. Open the file, choose **Save as**, and save it as .docx, .xlsx or
  .pptx. Then add the new file and remove the old one.

## Limits

- Up to 25 MB for each file.
- Up to 100 files and 250 MB in all for each app, its goals included.

## When agents get a change

Agents get fresh copies of the files each time they start. Work that is
already running keeps the copy it has until it next starts. The same goes for a
file you remove.

## Where your files go

- The originals stay on your PC, in Decurion. Agents only get copies.
- Files never go to GitHub on their own. A file reaches GitHub only if an agent
  puts it in the app's code on purpose, for example a logo the task asked for.
  You see it in the pull request before you merge.

## Remove a file

1. Next to the file, click **Remove**.
2. Click **Remove** in the box that asks you to confirm.

## If something goes wrong

- **"This file is larger than 25 MB."** Make the file smaller, for example by
  saving a PDF at a lower quality or splitting it, and add it again.
- **The app has run out of room.** Remove files you no longer need, then add
  the new one.
- **"Agents get a copy, but may not be able to read it."** Save the file as a
  PDF, .docx, .xlsx or .pptx and add it again.
- **"Not signed in."** Close Decurion and open it again, then click **Sign in** on the page that opens.
