Cloud worker

A cloud worker is a small server you rent. Your agents can work there while your PC is off or busy. Work moves between your PC and the cloud: open a card on the board and press Move to cloud or Move to PC.

Setting it up takes three steps and about half an hour, most of it waiting.

Your cloud workers

    1Make a Tailscale key

    Tailscale is the private network that already lets your phone reach your PC. The new server joins it the same way, with a key.

    1. Open your Tailscale keys page.
    2. Press Generate auth key. Leave the settings as they are: a key that works once is right.
    3. Press Generate key, copy it, and paste it here.

    The key stays on this page. Decurion never sends it anywhere: it only goes into the setup text in step 2, and it is forgotten when you close this page.

    2Create a server

    Rent a small server from any hosting company that offers Ubuntu and a user data box, for example Hetzner or DigitalOcean. Choose:

    • Ubuntu 24.04
    • 2 CPUs and 4 GB memory (more is fine)

    That costs about $5 to $25 a month, depending on the company.

    Phone access comes first. The cloud server reaches your PC the same way your phone does, over Tailscale, and that is not set up yet on this PC.

    Set up phone access over Tailscale, then come back to this page.

    Copy this setup text. While you create the server, look for the advanced options and paste it into the box called User data or Cloud config (Hetzner: "Cloud config"; DigitalOcean: "Advanced options", then "Add initialization scripts").

    This setup text works once, within 24 hours. It holds your Tailscale key and a one-time Decurion code, so do not share it.

    3Wait for it to connect

    Once the server is created, it sets itself up: it joins Tailscale, builds Decurion and then connects to your PC. The first time takes about 10 to 20 minutes. You can close this page and come back.

    Waiting for a setup text from step 2.

    If it has not connected after 40 minutes, delete the server at the hosting company and start again with a new setup text.
