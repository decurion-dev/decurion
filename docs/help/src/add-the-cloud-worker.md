# Add the cloud worker

This page helps you let agents work in the cloud, so work does not stop when your PC is off.

> **Coming soon.** This part of Decurion is still being built. This page shows how it will work.

## How it will work

1. On the board, open **Settings**, then click **Add cloud worker**.
2. Follow the three steps on screen.
3. Each piece of work can then run on **Your PC** or in the **Cloud**. You switch with one menu choice.

The same rules apply in both places. See [Choose your rules](choose-your-rules.md).

## What is true today

All work runs on your own PC, each piece in its own sealed workspace. When your PC is off, work waits. After a restart, work that was running picks up again when Decurion starts.
