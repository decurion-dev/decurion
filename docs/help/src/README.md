# What is Decurion

This page tells you what Decurion does and how to find help.

Decurion is a control room for AI coding helpers, such as Claude Code. We call each helper an **agent**. You give an agent a task, and it writes code for one of your apps.

Decurion lets you:

- See all your agents' work on one **board** in your web browser.
- Answer the things that need you from your **phone**.
- Keep each agent in its own **sealed workspace**, a closed-off space on your PC. An agent can only change its own copy of your app's code. It cannot see your other files or your passwords.

Decurion is free and open source. It runs on your own PC. Windows comes first. Mac and Linux work too, with a few extra steps.

> Decurion is in early development. Some parts are still being built. Pages that describe those parts start with a **Coming soon** note.

## How the pieces fit

1. You add an **app**. That is a folder on your PC that holds your app's code.
2. You add **work** for that app. That is a task, written in plain words, such as "Add a password reset page."
3. Decurion makes a fresh copy of the app's code and starts an agent in a sealed workspace.
4. The agent works and saves its changes in its own copy.
5. When it is done, the work shows up for your review. You accept it, send it back, or reject it.

## The words you will see

Every piece of work is in one of these states. You see the same words on the board and on your phone.

| Word | What it means |
| --- | --- |
| Queued | Waiting to start. |
| Running | An agent is working on it. |
| Needs you | It stopped and is waiting for you to decide something. |
| In review | The agent finished and saved its changes. Look at it and decide. |
| Done | You accepted it. |
| Failed | It could not finish. You can try again. |
